# Caesar's Loot audio

Milestone 10 uses the procedural Web Audio fallback in `SoundManager`, so the production bundle currently adds no encoded audio weight. Future licensed assets belong in the category folders below and must keep the same semantic cue names.

- `ui/`: buttons, hover and tile press
- `gameplay/`: reveal, loot, trap, cashout, win and lose
- `character/`: character reactions
- `ambient/`: reserved for a later lightweight ambience layer

Audio is optional: blocked or unavailable Web Audio never blocks gameplay.
